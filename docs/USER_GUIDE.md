# 观星录 · 使用指南

> 面向第一次打开这个页面的人。不讲命理，只讲**点哪里、看什么、别误读什么**。
> 五分钟能走完一遍。

---

## 0. 先说清楚它是什么

它不是一个游戏：没有关卡、没有抽卡、没有积分、没有排行榜，也没有任何付费入口。

它是一个**查询与阅读工具**，用法是三步：

```
填出生信息  →  得到一张可核对的结构图  →  读解释（并自己判断）
```

「好玩」的部分不在闯关，而在：你第一次看到自己的时间被拆成八个字、五个行、十个关系，
而且**每一个数字都能拿万年历核对**。这种「可验证」的感觉，是很多命理 App 不提供的。

## 2. 第一步：排盘（观星）

### 2.1 填表

打开 `/bazi`，从上往下四块：

**① 历法**
默认公历。如果你只知道农历生日，点「农历」——年/月/日会变成三个下拉框，
该年的闰月会自动出现在列表里（显示为「闰 2 月」这种），大小月也会限制可选天数。

**② 出生时间**
直接选时:分。**不知道就勾右上角「时辰未知」**——这是这个工具比较诚实的地方：
它会留空时柱，而不是随便给你补一个。

> 为什么时辰重要：时柱影响子女、晚年，也影响大运的起运时间。留空的话，大运仍会推，
> 但会以正午 12:00 代入，并在结果页标注「实际起运年份可能相差数月」。

**③ 性别**
只有三个选项：男 / 女 / 不填。它**只用于决定大运顺排还是逆排**（阳男阴女顺排、阴男阳女逆排），
不用于任何性格判断。不想填就选「不填」，那就只排四柱、不推大运。

**④ 出生地（可选）**
输入城市名（如「杭州」）会弹出候选，选中后自动带出经度。
也可以直接填经度（东经为正、西经为负）。

下面有个勾选框「启用真太阳时校正」：

- **默认关闭**。因为大多数人的排盘习惯是直接用北京时间，关了才能和别的工具对上。
- 打开后，会按经度差 + 均时差修正时刻。乌鲁木齐一带能差两小时以上，
  14:30 出生的人校正后可能落到「午时」而不是「未时」——**时柱会变**，这是正常的。
- 想验证效果：随便填个 1990-05-15 14:30、出生地选乌鲁木齐，勾上前后对比时柱。

**⑤ 排盘口径（高级）**
默认折叠。里面只有一项可调：晚子时（23:00–24:00）出生的人，日柱算次日还是当日。
两个流派都有人用，默认「归次日」。

点「开始排盘」。

### 2.2 看命盘

结果页从上到下：

| 区块 | 看什么 | 别误读 |
| --- | --- | --- |
| 顶部大字 | 四个干支 + 农历 + 属相 + 日主 | 这就是你的八字，八个字 |
| 黄色提示条 | 夏令时、时辰未知等提醒 | 出现说明计算有前提，不是出错 |
| 宣纸四柱表 | 每柱的天干地支、十神、藏干、纳音、地势、旬空；底部胎元/命宫/身宫/胎息 | 藏干小字是「地支里藏着的天干」，不是装饰 |
| 五行分布 | 五条彩色条 + 右侧三个数 | 条长按「藏干加权」，×n 是「本气计数」。**「缺」不等于要补** |
| 旺衰评估 | 一个 0–100 的分和三项依据 | 这是简化模型，不是定论；分数低不等于命不好 |
| 大运 | 一排十年一格的卡片，**可以点** | 点开某一运，下面会展开这十年每一年的干支与十神 |
| 刑冲合会 | 四柱之间的合、冲、半合 | 只列结构，不判吉凶；冲主变动，变动本身无好坏 |
| 计算依据 | 立春换年、节气定月、子时规则、真太阳时偏移 | 拿别的工具对不上时，先看这一块 |

页面顶部有三个按钮：

- **AI 解读** → 进入解读页（下一步）
- **打印 / 存 PDF** → 浏览器打印对话框，选「另存为 PDF」就是一份报告
- **分享链接** → 手机上调起系统分享，电脑上复制链接

### 2.3 如果和别的 App 算出来不一样

九成是这四个口径之一，页面「计算依据」里都写了你当前用的是哪种：

1. **年柱按立春还是正月初一换**（本工具：立春）
2. **月柱按节气还是农历月**（本工具：节气）
3. **晚子时日柱归哪一天**（本工具：默认归次日，可切）
4. **是否做真太阳时校正**（本工具：默认不做）

四项都对齐了还不一样，才值得怀疑是 bug。

## 3. 第二步：读解读（知己）

点「AI 解读」进入 `/bazi/reading`。这一页分两层：

**上层：规则解读（不依赖 AI，一定有内容）**

八个板块，页首有目录可跳转：

1. 命盘结构 —— 先讲这张盘怎么读
2. 日主气象 —— 你的日干对应哪种意象（如「甲木＝参天之木」），有长处也有另一面
3. 五行分布 —— 哪一行最盛、哪一行最弱，传统怎么看
4. 旺衰与取用 —— 偏强/中和/偏弱，以及传统上「泄」还是「扶」
5. 十神结构 —— 哪种关系出现最多，分别意味着什么
6. 刑冲合会 —— 结构上的动与合
7. 大运流年 —— 当前走哪一步运
8. **可以问自己的问题** —— 这一节最值得看，它把术语换成了能自问的话

**下层：AI 语言转译（需要服务端配置模型密钥）**

- 有配置：点「生成解读」，等十几秒，得到一篇 600–900 字的转译；下面还能继续追问。
- 没配置：这一块会显示「模型未配置」和配置方法，**其余功能完全不受影响**。

追问怎么写才有用？对比一下：

| 没什么用 | 有用 |
| --- | --- |
| 「我什么时候发财」 | 「我的盘里财星落在哪一柱，传统上怎么解释这个位置？」 |
| 「我命好不好」 | 「日主偏弱但食神多，传统上会建议往哪个方向用力？」 |
| 「我该不该辞职」 | 「从五行结构看，我在压力大的环境里通常是什么反应模式？」 |

前一类问题任何工具都只能给你套话；后一类问题，模型才有东西可讲。

## 4. 第三步：问卦（易）

打开 `/yijing`，三种起卦方式选一种：

### 铜钱摇卦（最有仪式感）

1. 心里先把要问的事想清楚（一件事一卦，别问「我这辈子怎么样」）
2. 点「摇第 1 爻」→ 三枚铜钱翻转约 0.8 秒 → 落定，记录一爻
3. 重复六次，从下往上成一卦
4. 六爻完成后自动出结果

规则写在按钮下面：背记 3、字记 2，合计 6 老阴 / 7 少阳 / 8 少阴 / 9 老阳。
老阴老阳是「动爻」，会让卦发生变化。

### 时间起卦（梅花易数）

点一下就用当前时刻起卦。**同一时辰内起卦结果相同**——这是规则，不是 bug。
上卦=（年支数+月+日）÷8 取余，下卦=（年支数+月+日+时支数）÷8 取余，动爻=总和÷6 取余。

### 数字起卦

填两个正整数。上卦=第一个数÷8 取余，下卦=第二个数÷8 取余，动爻=两数之和÷6 取余。

### 看结果

| 部分 | 含义 |
| --- | --- |
| 左：本卦 | 当下的处境 |
| 右：变卦 | 有动爻时才会出现，表示趋向；没有动爻就是「静卦」，只看本卦 |
| 朱红色爻线 | 动爻，右侧有 ○（阳动）或 ×（阴动） |
| 卦辞与爻辞 | 《周易》通行本原文（保留繁体），白话是本项目写的 |
| 起卦过程 | 点开可以逐步核对取数算式 |

看完可以点「保存这一卦」存进本地记录，或「再起一卦」。

## 5. 第四步：择时（黄历）

打开 `/almanac`：

- 顶部可以选任意日期（前一天 / 日期框 / 后一天 / 回到今天）
- 主卡左边是公历+农历+干支+生肖+星座+值星+星宿+冲煞
- 主卡右边是「今日节气」或「下一个节气还有几天」，以及**宜忌**
- 下面是一整年的 24 节气表，点任一项跳到那天的黄历；已过的节气是灰的
- 再下面是四张文化卡片，解释「为什么立春换年」「宜忌是怎么来的」

**重要**：宜忌右上角标了「通书整理」。农历、干支、节气是天文算法算出来的（可复算），
宜忌是传统通书的条目整理（文献传承）——两者性质不同，别当成一回事。

## 6. 第五步：藏经（词典）

打开 `/canon`：

- 搜索框支持术语、释义、拼音（试试搜「藏干」「真太阳时」）
- 六个分类筛选：全部 / 基础 / 结构 / 十神 / 历法 / 占卜
- 点任一条展开详情
- 页面下方还有「流派」（子平术、盲派、调候派、紫微斗数）和「古籍」（渊海子平、三命通会等）介绍

读到不懂的词，从这里查，比在解读页猜要快。

## 7. 记录、隐私、删除

### 记录在哪

打开 `/history`，或首页往下滑的「最近的测算」。

- 全部存在**这台设备的浏览器里**（localStorage），没有账号，不同步云端
- 换浏览器、换设备、清理浏览器数据 → 记录就没了，这是设计如此
- 想单条删：点右侧 × → 再点「删除」
- 想全删：右上「清空全部」→「确认全部删除」

### 隐私要点

1. 出生信息**只在本机**参与计算，不上传服务器
2. 只有你点「AI 解读」时，服务端才会收到排盘所需的出生信息（不含姓名，因为根本不收集）
3. 分享链接会把生日参数编进 URL，**发之前确认对方可以知道这些**
4. 共用电脑上用完，建议去「记录」页清空

### 设置在哪

`/settings`（页脚「设置与隐私」）：

- 改默认口径（子时流派、默认是否开真太阳时）
- 开关历史保存
- 看 AI 服务是否已配置
- 一键清空本地数据
- 读隐私说明、关于、开源致谢

## 8. 手机上怎么用

页面是响应式的，手机上：

- 顶部导航收成右上角「三条线」按钮，点开是两列菜单
- 四柱表**仍是四列**（信息结构不能塌），字会小一点
- 五行条形、旺衰刻度自动变窄
- 摇卦按钮变成整行宽

两个小技巧：

1. **加到主屏**：Safari 分享 → 添加到主屏幕；Chrome 菜单 → 添加到主屏幕。之后像 App 一样打开。
2. **存 PDF**：命盘页点「打印 / 存 PDF」→ 在打印预览里用双指缩放，选择「存储到文件」。

## 9. 怎么让别人也能用

分三种情况，按需选。

### A. 同一个 Wi-Fi，临时给别人看（最快）

如果服务跑在某台电脑上，同一局域网内的手机/平板可以直接访问：

```
http://<这台电脑的局域网 IP>:3100
```

例如本机当前是 `http://192.168.43.12:3100`（IP 会变，用 `ipconfig` 查「IPv4 地址」）。

注意两点：

1. 电脑不能休眠、不能关掉那个终端窗口
2. Windows 首次可能弹防火墙提示，要允许「专用网络」；否则手机打不开

### B. 部署到公网，任何人随时访问（正式做法）

最短路径是用 Vercel（免费额度够个人用）：

```bash
npm i -g vercel
cd guanxinglu
vercel            # 按提示登录、确认
vercel --prod     # 发布，得到一个 https 链接
```

要启用 AI 解读，在 Vercel 项目的 Settings → Environment Variables 里加：

```
AI_PROVIDER=openai
AI_API_KEY=sk-...
AI_BASE_URL=https://api.openai.com/v1
AI_MODEL=gpt-4o-mini
```

不配也能上线，只是解读页会显示「模型未配置」。

想用自己的服务器 / 国内访问更快，见 `docs/DEPLOYMENT.md`（Docker + Nginx 配置、
备案、成本估算都在里面）。

### C. 只把某一次结果发给别人

命盘页点「分享链接」，会复制一个带参数的地址（如 `/bazi/result?y=1990&m=5...`）。
对方打开就能看到同一张盘，不需要填表。

**这条链接里含出生日期、时间、出生地经度**，只发给可以知道这些信息的人。

### 发给别人的一句话（可以直接抄）

> 这是一个看八字的工具，不收费也不用注册。打开后点「开始排盘」，
> 填生日和出生时间（不知道时辰可以勾「时辰未知」），就能看到四柱、五行和大运。
> 数据只存在你自己的浏览器里，不会上传。

## 10. 常见问题

**Q：为什么「缺木」的提示旁边还写着「不等于需要补」？**
因为「缺」只是说八个字的本气里没有木。要不要在结构上引入木，取决于日主强弱与整体流通。
「缺什么补什么」是商业话术的简化，不是命理共识。

**Q：旺衰分数低是不是命不好？**
不是。它只是一个 0–100 的结构评分，衡量日主得到的生扶比例。
这个模型是本项目简化的三要素法（得令/得地/得势），页面底部写明了它的局限。

**Q：AI 按钮点了没反应 / 一直转圈？**
先看 `/settings` 里「AI 解读服务」是不是「未配置」。未配置时不会生成，但规则解读照常显示。
如果是「已配置」但报错，通常是密钥失效、额度用尽或网络不通，页面上会给出具体错误。

**Q：为什么命盘页的「真太阳时」显示未启用？**
默认就是关闭的。要开启需要先填出生地（或经度），否则没有校正依据。

**Q：记录会同步到我的其他设备吗？**
不会。没有账号系统，数据只在本机浏览器。这也是它不需要你注册、不上传生日的原因。

**Q：可以离线用吗？**
首次加载后，排盘、起卦、黄历、词典都在浏览器里算，断网也能继续用当前页面；
但刷新页面需要重新加载资源。AI 解读必须联网。

## 11. 边界（请认真读一遍）

- 它**不预测**。命理属于传统文化范畴，不具备科学预测能力。
- 它**不能**作为医疗、投资、法律或重大人生决策的依据。
- 它**不制造恐惧**。没有「血光之灾」「破财」这类话术，也没有任何付费解锁。
- 它**不替你下结论**。同一个盘，不同流派说法不同，页面只标注口径，判断权在你。

如果哪天它开始用恐吓换钱，那它就变成了另一个东西——那不是这个项目想做的。

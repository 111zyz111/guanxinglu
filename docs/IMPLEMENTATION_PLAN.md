### 验证中发现并修复的问题

| 问题 | 表现 | 原因 | 修复 |
| --- | --- | --- | --- |
| 五行条形不可见 | 只有一条极淡的线，看不到填充 | `linear-gradient(90deg, var(--wx-mu)66, ...)` 把透明度后缀拼在 CSS 变量后面，是非法值，整个 `background` 失效 | 改用 `color-mix()` 生成渐变，并加 `backgroundColor` 兜底；条高 6→8px |
| 节气表少一项 | 年度表只有 23 个节气，12 月下旬「下一个节气」为空 | `getJieQiTable()` 按农历年组织，单表不含本年末冬至 | 探测前后相邻年份共 5 张表后按公历年过滤（见技术设计 §6.5） |
| 首页星图压住副标题 | 星座连线穿过「察己心」 | 装饰层位置与高度过大 | 上移并降低不透明度（0.6→0.4） |
| 卦象标题重复 | Unicode 卦符与手绘爻线重复表达同一件事 | 设计冗余 | 去掉 Unicode 卦符，只保留卦名 + 上下卦 + 卦序 + 手绘爻线 |
| 经度单位文案不准 | 输入框后缀写「°E」，但支持负数（西经） | 文案与校验范围不一致 | 改为「°（东经为正，西经为负）」 |
